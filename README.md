# QuantScope · 环球市场量化分析台

一个适合个人研究的本地量化分析看板。它可以查看恒生科技、恒生指数、纳斯达克、S&P 500、中国 A 股指数与全球资产，并输入股票代码计算趋势、动量、成交量、波动率、多模型估值、财务质量、风险统计和经过历史回测的多因子信号。

## 启动

macOS 用户可以直接双击 `start.command`，它会启动本地服务并打开浏览器。

启动脚本默认尝试 `5173` 端口；如果旧版本服务仍占用该端口，会自动切换到下一个空闲端口，并用随机参数打开页面，避免连到旧服务或命中浏览器缓存。

在这个文件夹内运行：

```bash
python3 server.py
```

然后打开：<http://127.0.0.1:5173>

如果 Finder 提示 `start.command` 没有适当权限，请打开“终端”执行下面两行；第二行会直接用 zsh 运行脚本，不依赖 Finder 的执行权限：

```bash
cd /path/to/quant-market-lab   # 换成你电脑上项目文件夹的路径
zsh start.command
```

也可以完全绕过启动脚本：

```bash
cd /path/to/quant-market-lab   # 换成你电脑上项目文件夹的路径
python3 server.py
```

保持终端窗口打开，然后访问 <http://127.0.0.1:5173>。

## 支持的代码格式

- 美股：`AAPL`、`NVDA`、`TSLA`
- 港股：`0700.HK`、`9988.HK`
- 新加坡股：`D05.SI`、`O39.SI`、`U11.SI`
- 日股：`7203.T`、`6758.T`；韩股：`005930.KS`、`000660.KS`
- A 股：可输入 `600519`、`300750`，系统分别补全为 `600519.SS`、`300750.SZ`；也支持直接输入带后缀代码
- 指数：`HSTECH.HK`、`^HSI`、`^IXIC`、`^GSPC`、`000001.SS`、`000300.SS`、`000905.SS`、`399006.SZ`、`000688.SS`

行情由 Yahoo Finance 图表接口提供，服务端只做本地转发和 60 秒缓存。接口无法访问时，界面会自动切换为演示数据并显示 `DEMO`，不要把演示数据用于交易。

## 自选、仓位与期权

- 自选池与仓位记录保存在当前浏览器的 `localStorage`，不会上传到服务端。
- 仓位可记录多/空、股票/期货/加密资产/期权、数量、平均成本和手动标记价；没有手动标记价时使用最新可用行情估算浮盈亏。
- 期权实验台支持 Call/Put、买入/卖出、到期日、行权价、隐含波动率、无风险利率、合约乘数和合约数量。
- 输出 Black–Scholes 理论权利金、Delta、Gamma、Vega、Theta、盈亏平衡、最大亏损和标的 ±5% 到期情景。
- 期权实验台不是实时期权链，也没有纳入美式提前行权、分红、波动率微笑、买卖价差、手续费和滑点。

## v2.5 一键截长图

右上角新增 **“⤓ 截长图”** 按钮：把当前标的的当日量化分析拼成一张 PNG 长图并直接下载，文件名形如 `QuantScope_AAPL_20261026-1054.png`。

- **包含**：报告抬头（生成时间、最近交易日、数据状态和目录）→ 模型结论 → 核心指标 → 价格结构与模型拆解 → 估值中心 → 基本面与财务质量 → 新闻情绪 → 量化统计 → 信号回测 → 交易计划与风险 → 每日行动建议 → 免责声明。指数、期货、外汇、加密资产没有估值和基本面，这两块会自动跳过。
- **不包含**：全球市场、情绪温度计、十大新闻、热榜、自选仓位、期权实验台等与这只标的无关的面板，以及刷新、重新估值这类按钮。
- **截全**：新闻情绪“其余 n 条”会展开；页面里需要横向滚动的宽表（如 DCF 现金流预测）会等比缩小到完整显示；你在估值假设里改过的数值会原样保留。
- **清晰度**：按当前页面宽度排版，以 2 倍像素输出（桌面约 2300 px 宽、1–1.3 万 px 高，PNG 约 8–13 MB）；页面特别长时会自动降低倍率，避免超过浏览器画布上限。
- 如果点按钮时行情、财报或新闻情绪还在加载，会先等它们加载完（最多 20 秒）再截图。
- 纯本地实现（`snapshot.js`，不依赖任何第三方库，也不联网）：把各面板连同页面自己的样式放进 SVG `foreignObject` 绘制到画布上再导出 PNG。建议用 Chrome / Edge；如果浏览器禁止导出这类图片，会提示改用 Chrome。

## v2.4 指数、期货、外汇和加密资产的新闻情绪

“新闻情绪”面板不再只限个股：输入指数（如 `^GSPC`、`^HSI`、`000300.SS`、`^VIX`）、期货（`CL=F`、`GC=F`、`ZN=F`）、外汇（`EURUSD=X`、`JPY=X`、`CNY=X`）、贵金属现货（`XAUUSD=X`）或加密资产（`BTC-USD`、`ETH-USD`）都会计算新闻情绪，算法和个股相同：相关度 × 3 天半衰期加权，再向 0 收缩。

和个股的区别：

- **按资产找新闻**：每个资产有预设的英文和中文检索词，例如美元/日元用 `"USD/JPY" OR USDJPY`、`"yen" forex OR currency`、`美元兑日元 OR 日元汇率`；恒指用繁体港股新闻和英文新闻；A 股指数用简体新闻。几个检索结果轮流取，合计最多 40 条，避免某一个检索词的结果占满。没有预设的期货、指数会用 Yahoo 返回的名称检索（例如 `KC=F` → “Coffee”）；没有预设的外汇对会按货币代码自动生成检索词。
- **明确的方向约定**：提示词和面板上都会写清“正分是什么意思”。外汇：正分 = 基础货币升值（`JPY=X` 即 USD/JPY 上升 = 美元走强）；VIX：正分 = VIX 上升（恐慌加剧）；国债期货：正分 = 期货价格上涨（收益率下降）；其他资产：正分 = 价格 / 点位上涨。
- **跨资产的提示词和事件分类**：相关度按资产类别定义（例如外汇看两国央行、利率、通胀、贸易和资本流动；加密资产里全行业监管和 ETF 资金流算中等相关）；事件分为央行与利率、宏观数据、财政与产业政策、地缘政治、贸易关税、供需库存、资金流向、采用与机构化、安全事件、技术面与情绪等，不同资产只允许各自适用的类别。
- **缓存**：个股的打分缓存键不变，已有的打分继续有效；非股票资产使用单独的提示词版本号，以后改提示词不会混用旧分数。

同样每天记录一次，并用面板里的前向检验（情绪 vs 未来 5 日收益）观察是否有效，**不计入综合评分**。命令行批量记录：

```bash
python3 news_sentiment.py ^GSPC ^HSI 000300.SS CL=F GC=F JPY=X EURUSD=X BTC-USD
```

## v2.3 市场整体情绪与今日十大新闻

首页“全球市场”看板上方新增两个面板，打开页面自动加载，每 15 分钟刷新一次情绪读数；面板右上角的“刷新”会跳过缓存重新计算。

### 市场情绪温度计（恐惧 / 贪婪，0–100）

美股、港股、A 股各一个读数。每个分项先算原始值，再换算成**它在过去 252 个交易日里的分位数**（至少 120 天才出数），按方向调整成“0 = 极度恐惧、100 = 极度贪婪”，最后等权平均。分位法的好处是不需要人为设阈值，各分项天然可比，也不会用到未来数据。

| 市场 | 分项（括号内为方向） |
|---|---|
| 美股 | S&P 500 相对 125 日均线（+）· 11 个 SPDR 行业 ETF 站上 50 日线的比例（+）· VIX 相对 50 日均线（−）· VIX / VIX3M 期限结构（−）· SPY − TLT 20 日收益差，股债避险需求（+）· HYG − IEF 20 日收益差，信用利差（+） |
| 港股 | 恒指相对 125 日均线（+）· VHSI 相对 50 日均线（−）· 恒生科技 − 恒指 20 日收益差（+）· 12 只港股龙头站上 50 日线的比例（+） |
| A 股 | 沪深 300 相对 125 日均线（+）· 20 日已实现波动率（−）· 沪深两市成交额 5 日 / 120 日均值（+）· 两融余额 20 日变化（+）· 中证 1000 − 沪深 300 20 日收益差（+） |

- 分档：0–25 极度恐惧、25–45 恐惧、45–55 中性、55–75 贪婪、75–100 极度贪婪。
- 至少 60% 的分项有数才出综合分；某个分项断更最多向前填补 5 个交易日。
- **盘中处理**：交易时段内最后一根日线还没收盘，成交额类分项会剔除这根未完成的 K 线，读数旁标“盘中”；回测也不使用盘中点。
- **A 股盘面快照**（不计入综合分）：上涨 / 下跌 / 平盘家数、涨停 / 跌停家数、两市成交额。
- **历史回测**：面板会列出过去几年各情绪区间之后 20 个交易日的指数平均收益、胜率，以及情绪分与未来收益的 Spearman IC（按 20 日重叠样本折算有效样本数后给出 t 值）。从已有数据看，极度恐惧区间之后的平均收益反而更高（逆向特征），但 IC 在统计上并不显著，**只作为温度计参考，不计入个股综合评分**。
- 每日读数写入 `data/sentiment.sqlite` 的 `market_daily` 表，便于以后自己做研究。

数据来源：东方财富指数 / ETF / 港股日线与两融数据（免费、无需 key），Yahoo Finance 的 `^VIX`、`^VIX3M`（Yahoo 不可用时美股改用 S&P 500 的已实现波动率替代 VIX 两项，状态栏会注明）。

### 今日市场十大新闻

1. 抓取过去 24 小时的新闻：Google News 商业头条（英文）、Google News 美股、Google News A 股（简体）、Google News 港股（繁体）、东方财富 7×24 要闻。
2. 去重合并：标题按英文词 / 中文双字做 Jaccard 相似度，≥ 0.55 视为同一事件，合并来源、覆盖媒体数和链接。
3. 预评分：来源权重、在源中的排名、覆盖媒体数、新鲜度、是否含市场关键词（央行、利率、财报、关税、指数等），取前 60 条作候选。
4. **LLM 精选**（沿用 v2.1 的 SoCLaaS 配置）：从候选中选出最重要的 10 条，合并重复事件，给出中文标题、一句话摘要、分类、影响市场（美股 / A 股 / 港股 / 全球）、情绪（−1 到 +1）、重要度和相关资产，并写一段今日市场总览。
5. 汇总：按重要度加权平均每条新闻的情绪，得到“新闻面情绪”，标为“全球”的新闻同时计入三个市场。

没有配置 SoCLaaS key 时，十大新闻会按热度和关键词排序（并保证至少 2 条 A 股、2 条港股新闻），显示原文标题，不打情绪分，状态栏显示“未配置 LLM · 按热度排序”。新闻结果缓存 30 分钟，情绪读数缓存 15 分钟。

## v2.1 新闻情绪因子（NUS SoCLaaS · LLM）

新增“新闻情绪 / NEWS SENTIMENT”面板：抓取个股最近 14 天新闻（Yahoo Finance + Google News RSS），用学院提供的 SoCLaaS 大模型（OpenAI 兼容接口，默认模型 `x-test-1`）逐条打分，汇总成一个 [−1, 1] 的情绪因子。v2.4 起指数、期货、外汇和加密资产也适用，见上文 v2.4 一节。

### 配置（一次即可）

1. 在 <https://soclaas-portal.comp.nus.edu.sg> 申请 API key；接口地址见 SoCLaaS 文档。
2. 把 `soclaas.env.example` 复制为 `soclaas.env`（同一文件夹），填入：

   ```
   SOCLAAS_API_KEY=你的 key
   SOCLAAS_BASE_URL=https://……/v1
   SOCLAAS_MODEL=x-test-1
   ```

3. 测试连接，然后重启 QuantScope：

   ```bash
   python3 news_sentiment.py --check
   ```

新闻打分默认用 `x-test-1`（GLM 5.3 Flash，便宜、适合批量）；它被 SoCLaaS 撤下时会自动改用 `SOCLAAS_FALLBACK_MODEL`（默认 `default`，即 SoCLaaS 当前推荐的通用模型）。可用模型列表：`curl -H "Authorization: Bearer $SOCLAAS_API_KEY" https://soclaas-api.comp.nus.edu.sg/v1/models`。

`soclaas.env` 只存在你自己的电脑上，已写入 `.gitignore`；key 不会发送到浏览器。也可以改用同名环境变量。SoCLaaS 换模型时只改 `SOCLAAS_MODEL` 一行。

常见错误：`HTTP 404` 一般是地址少了或多了 `/v1`，或模型已下线；`认证失败` 检查 key；`无法连接` 在校外先连 NUS VPN；`SSL 证书校验失败` 运行 “/Applications/Python 3.x/Install Certificates.command” 或 `pip3 install certifi`。

### 打分与汇总

- 每条新闻输出：相关度（0–1）、情绪（−1 到 1）、事件类型（业绩、指引、并购、监管、诉讼……）和一句理由；`temperature = 0`，要求 JSON 输出。
- 每次请求最多 15 条一起打分；结果按“提示词版本 + 模型 + 代码 + 标题”缓存在 `data/sentiment.sqlite`，同一条新闻不会重复调用模型。限流（429）和服务端错误自动指数退避重试。
- 情绪因子 = Σ(相关度 × 0.5^(天数/3) × 情绪) ÷ (Σ权重 + 1)。分母里的 +1 是中性先验：只有一条新闻时分数自动减半，新闻越多、越新、越相关，越接近加权均值。
- ≥ +0.35 明显偏多，≥ +0.12 偏多，≤ −0.12 偏空，≤ −0.35 明显偏空；证据强度 < 0.3 显示“证据不足”。

### 为什么不计入综合分

新闻无法回放 5 年做回测，所以情绪因子先单独展示。每次计算会把当天的分数写入 `daily` 表，面板用“记录日的分数 vs 之后 5 个交易日收益”做前向检验（Rank IC、t 值、方向命中率），满 20 天才显示。IC 稳定为正之后，再考虑给它一个权重。

只在你打开某只股票的那天才会记录。想每天自动记录一批股票，可以在终端运行（或交给 cron / launchd 每天跑一次）：

```bash
python3 news_sentiment.py AAPL NVDA 0700.HK D05.SI 600519
```

（A 股请写全后缀，例如 `600519.SS`、`300750.SZ`。）

### 局限

- LLM 只看标题，可能误判、也可能对旧闻反应过度；重要新闻请点开原文。
- Google News 对 A 股、港股小盘股覆盖有限；英文公司名搜中文新闻会漏。
- `x-test-1` 是 SoCLaaS 的试用模型，可能被替换；换模型后旧缓存不会复用（缓存键包含模型名），历史分数也可能出现断点。

## v2.0 更新摘要

- **估值中心**：三阶段 FCFF DCF、反向 DCF、WACC × 永续增长敏感性表、2,000 次 Monte Carlo DCF、剩余收益模型（RI）、股东回报折现（股息 + 回购）、历史估值中枢、同业倍数，汇总为加权公允价值与区间（football field）。全部假设可在页面上修改并即时重新估值；接口不可用时可以手动录入基本面。
- **基本面与质量**：ROIC、ROIC − WACC、ROE、利润率、FCF/净利润、应计比率、利息保障、净负债/EBITDA、营收与 EPS CAGR；Piotroski F-score（9 项）与 Altman Z″-score。
- **量化统计**：1Y/3Y/5Y 年化收益、波动、Sharpe、Sortino、最大回撤；历史 / 正态 / Cornish–Fisher VaR 与 CVaR；偏度、峰度、Jarque–Bera 检验；EWMA 波动、波动分位；方差比检验；对本地基准的 CAPM 回归（β、Blume β、Jensen α 及显著性、R²、特质波动、信息比率、上下行捕获）；收益分布图、回撤水下图、月度收益热力图、波动率价格锥。
- **信号回测**：用 5 年日线逐日重算技术分，统计未来 20 日收益的分组均值、胜率、t 值和信息系数 IC，并与买入持有对比权益曲线；“历史胜率（收缩）”取代了 v1.1 里凭经验写死的置信度公式。
- **修正的问题**：
  - v1.1 的正态分布函数实现有误（N(0) 返回 0.75），导致期权实验台的 Black–Scholes 价格和希腊值都偏了；现已修正（S=K=100、σ=20%、r=5%、T=1 年的看涨期权 = 10.45）。
  - Beta 原来用 60 个日收益、按数组尾部对齐、且所有市场都对 S&P 500 回归；现在按日期对齐，用 2 年周收益对本地基准回归（港股→恒指、A 股→沪深300、新加坡→STI、日本→日经、韩国→KOSPI）。
  - 收益类统计改用复权价（拆股、分红），指标统一在 5 年日线上计算，不再随图表区间（1M/3M…）变化；图表区间只影响显示。
  - 切换代码时如果上一次请求还没返回，新的请求会被忽略；现在以最新请求为准。
  - 估值假设表单的数字步长会触发浏览器校验、阻止提交，已关闭该校验。

## 模型说明（v2.0）

综合分 = 10 × Σ(权重 × 因子) / Σ(可用因子的权重)，每个因子都是 [−1, 1] 的连续值，缺失的因子（例如指数没有估值）按权重重新归一化：

| 因子 | 权重 | 内容 |
|---|---|---|
| 趋势结构 | 25% | 价格/MA20、MA20/MA60、MA200 的波动率标准化距离；12-1 月动量 ÷ 年化波动（风险调整动量） |
| 动量状态 | 15% | MACD 柱 ÷ (价格 × 日波动)；RSI 分段映射（70 以上逐步转为过热惩罚，30 以下给反弹分） |
| 成交确认 | 5% | log(成交量 / 前 20 日均量) × 当日方向；无可靠成交量的品种不计入 |
| 市场环境 | 15% | 本地基准 1M / 3M 收益；同时用于门控（风险收缩时提高做多门槛） |
| 风险状态 | 10% | 60 日年化波动相对资产类别基线、距 52 周高点的回撤 |
| 估值安全边际 | 20% | tanh(综合公允价值偏离 / 30%) × 模型可靠度（各模型越一致越可靠） |
| 财务质量 | 10% | Piotroski F、ROIC − WACC、Altman Z″ 区间、应计比率 |

信号：综合分 ≥ +2.5 为做多、≤ −2.5 为偏空（期货、加密资产为 ±3.0）。情景计划仍用 1.6 × ATR 止损、2R 目标。

### 估值方法

- **折现率**：Ke = rf + β × (成熟市场 ERP + 国家风险溢价)；β 为回归 β 的 Blume 调整值；WACC 按市值和有息负债加权。默认 rf 为 2026 年 8 月下旬各国 10 年期国债收益率（美元在服务可用时用 ^TNX 实时值覆盖），ERP 4.23% 为 Damodaran 2026 年 1 月隐含 ERP；全部可在页面修改。
- **币种**：模型在财报货币下用该货币的无风险利率折现，最后按即期汇率换算成交易货币（例如腾讯：人民币现金流、港币报价）。
- **DCF**：第 1–5 年 NOPAT 以 g₁ 增长，FCFF = NOPAT × 公司实际的现金转换率（近年 FCFF/NOPAT 中位数）；第 6–10 年增速线性回落到 g、转换率收敛到稳态值 1 − g/RONIC；终值用价值驱动公式 NOPAT × (1 − g/RONIC)/(WACC − g)；年中折现。金融企业不使用 FCFF DCF。
- **g₁ 的默认值**：分析师长期 EPS 增速（40%）、历史营收 CAGR（35%）、可持续增长 ROE × (1 − 股东回报率)（25%）加权，再向永续增长收缩 20%（增长率均值回归）。
- **剩余收益**：ROE 在 10 年内线性回到 (当前 ROE + Ke)/2，终值按 Ohlson 持续性系数 ω = 0.62 衰减；账面价值被大额回购扭曲（P/B > 4）时降低权重。
- **股东回报折现**：用近 3 年（股息 + 回购）/ 股；回报率低于 25% 的公司只作参照、不计入。
- **相对估值**：用“现价 × 参照倍数 / 当前倍数”的比值法，避免财报币种和交易币种不一致的问题；同业组可在页面修改。
- **综合价值**：一般公司 DCF 40% / 同业 20% / 历史 15% / RI 15% / 股东回报 10%；金融业 RI 45% / 股东回报 20% / 同业 20% / 历史 15%；REIT 以股东回报为主。单个模型先截尾到中位数的 1/3–3 倍再加权。分析师目标价只作参照。

### 数据来源与稳定性（v2.2 起免费数据源优先）

Yahoo 的 quoteSummary / fundamentals-timeseries 接口限流很严（HTTP 429）。v2.2 起，基本面优先走以下**免费、无需 API key** 的数据源，Yahoo 只在它们都失败时兜底：

| 市场 | 数据源 | 内容 |
|---|---|---|
| 美股（含 20-F 的 ADR，如 TSM） | [SEC EDGAR XBRL companyfacts](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)（美国证监会官方） | 10-K / 10-Q / 20-F 三大报表，按“最近一个财年 + 本年累计 − 去年同期累计”算 TTM |
| A 股（.SS / .SZ / .BJ） | 东方财富 F10 数据中心 | 一般企业 / 银行 / 证券 / 保险分别取对应报表 |
| 港股（.HK） | 东方财富港股 F10 | 长格式三大报表 + 公司资料（识别银行、保险、REIT） |
| 股价、总股本 | 东方财富 push2 行情 | ADR 自动按 ADS 口径换算（TSMC 1 ADS = 5 股） |
| 汇率 | Yahoo 图表 → 东方财富外汇 → open.er-api.com（日更） | 财报币种折算为交易币种 |

几点说明：

- **港股报表一律是人民币**：东方财富把所有港股报表折算成人民币（例如港交所 2024 年溢利 HK$130.5 亿显示为 120.8 亿），所以港股的财报币种按 CNY 处理，再按即期汇率折成港币。
- **SEC 的 User-Agent**：SEC 要求自动化程序带上联系邮箱。在 `server.py` 同目录新建 `datasources.env`，写一行 `QUANTSCOPE_SEC_EMAIL=你的邮箱`（参考 `datasources.env.example`）。不填也能用，但被 SEC 拒绝的概率更高。
- **缓存**：基本面结果缓存到 `data/fundamentals_cache/`（12 小时），重启服务不会重复下载；SEC 的公司全量 XBRL 文件较大（每家几 MB），首次打开某只美股会慢 1–3 秒。
- **滞后提示**：如果数据源里最新的财报超过 15 个月（常见于部分外国发行人，SEC 尚未收录其最新年报），估值中心会显示警告，并优先尝试 Yahoo。
- **免费源没有一致预期**：分析师目标价和长期 EPS 增速只来自 Yahoo，走免费源时增长假设改用历史营收 CAGR 和可持续增长率，估值中心状态栏会显示数据源和财报截止日。
- **新加坡、日本、韩国股票**仍只能用 Yahoo；Yahoo 返回 429 后服务会冷却 15 分钟不再请求，期间可以用“手动录入基本面”。如果你装了 `curl_cffi`（`pip3 install curl_cffi`），Yahoo 兜底会更稳定。

## 新加坡用户的通用交易流程

1. 先选择受监管、明确支持目标市场和产品的券商/期货商，在 MAS [Financial Institutions Directory](https://eservices.mas.gov.sg/fid/) 核对牌照、业务范围和产品权限。
2. A 股通常通过支持沪深港股通的券商访问合资格 A 股/ETF；可买清单、订单类型、交易时间、人民币结算和额度以 HKEX [Stock Connect](https://www.hkex.com.hk/Mutual-Market/Stock-Connect?sc=&sc_lang=en) 与券商当日规则为准。
3. 港股、新加坡股、美股分别确认交易所权限、币种、交易时间、结算方式、佣金和税费；第一次操作建议先用现金账户和限价单。
4. 原油/黄金期货交易前必须核对合约月份、合约乘数、最小跳动、保证金、换月和到期/交割安排。CME 的 [Gold Futures](https://www.cmegroup.com/markets/metals/precious/gold-futures.html) 与 ICE 的 [Brent Crude Futures](https://www.ice.com/products/219/Brent-Crude-Futures) 可作为合约规格入口。
5. 期权优先使用定义最大损失的策略；不要把“信号正确”误认为“账户能承受保证金波动”。SGX 要求交易成员取得客户对证券和期货风险的书面确认，参见 [SGX Risk Disclosure](https://rulebook.sgx.com/rulebook/416-risk-disclosure)。

建议把每笔交易的最大可接受亏损控制在账户净值的 `0.5%–1%`，用止损距离反推仓位，而不是先决定买多少股/多少张合约。这个比例只是风险控制示例，不是对你的账户的个性化建议。

## 重要提示

这是个人研究工具，不构成投资、税务、法律或交易建议。v2.0 已纳入财报与估值，但估值高度依赖增长、折现率和永续假设，回测也只是样本内检验；模型（综合分）仍没有纳入新闻、盘口、交易成本以外的冲击成本、流动性、停牌、借券、期权波动率曲面或券商准入约束。真实交易前应自行验证数据、做回测并设置仓位上限与止损。
